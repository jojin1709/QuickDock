# Support for QuickDock

Thank you for using QuickDock.

QuickDock is a free, native Windows 11 utility dock built by JOJIN JOHN. Because QuickDock is a local-first desktop application with zero cloud accounts and zero telemetry, all support is self-contained or handled through the channels below.

---

## Getting Help

### 1. Download & Updates
- Download the latest official Windows installer (`QuickDock-Setup.exe`) or portable package from the [Official GitHub Releases](https://github.com/jojin1709/QuickDock/releases/tag/v1.0.0).
- Check the [Changelog](CHANGELOG.md) for details on recent updates and bug fixes.

### 2. Bug Reports & Issues
If you encounter an issue, crash, or unexpected behavior on your desktop:
- Search existing [GitHub Issues](https://github.com/jojin1709/QuickDock/issues) to see if the problem has already been reported.
- If not, open a new issue describing:
  - Windows version and build number (e.g. Windows 11 23H2 x64)
  - Display configuration (single display, multi-monitor, DPI scale factors)
  - Steps to reproduce the issue
  - Expected vs. actual behavior
