Changelog

Track new features, performance updates, and bug fixes across QuickDock releases.

v1.0.2 — Full UI/UX & Functional Overhaul
November 1, 2026 · Official Production Release

Comprehensive remediation across all modules, replacing mock placeholders with live Windows APIs, hardware telemetry, and interactive controls.

Windows WASAPI Audio & Volume Synchronization

  • COM Endpoint Alignment: Fixed COM interface GUIDs for IAudioEndpointVolume and volume callbacks to official Windows SDK specifications.
  • Interactive Mute Toggle: Mute button responds immediately and synchronizes two-way with the OS mixer.

Live System Telemetry & Honest State

  • Zero Mock Data: Eliminated all hardcoded metrics (CPU, RAM, Disk, Battery, Network throughput) and mock clipboard items.
  • Live Weather Search: Geocoding and weather retrieval execute on Enter key with honest offline indicators.

View Activation & File Shelf Pickers

  • Native File & Folder Pickers: Added "Add Files..." and "Add Folder..." action buttons in File Shelf via WinRT.Interop.InitializeWithWindow.
  • View Loaded Hooks: Switching views automatically refreshes module telemetry and stored data.
v1.0.1 — Runtime Hardening & Release Gate
November 1, 2026 · Post-Gate Acceptance Pass

Targeted release hardening addressing multi-monitor physical display isolation, thread-safe clipboard marshaling, lifecycle resource stabilization, and standalone installer packaging.

Multi-Monitor Hardware Isolation

  • Independent Hit-Testing: Per-display notch instances operate isolated hover bounds, preventing notch duplication and crosstalk when moving cursor between monitors.
  • Mixed-DPI Calibration: Dynamic physical-to-logical coordinate scaling handles mixed scaling factors (125% laptop + 100% desktop) seamlessly.

Clipboard & UI Thread Reliability

  • STA Thread Marshaling: Resolved RPC_E_WRONG_THREAD (0x8001010E) exception by dispatching all clipboard events via DispatcherQueue.TryEnqueue().
  • Duplicate Suppression: Rapid successive identical clipboard updates are filtered without UI micro-stutters.

Packaging & Setup

  • QuickDock-Setup.exe: Single-file standalone installer with embedded installation archive and automated desktop/start menu shortcuts.
  • Self-Deleting Uninstaller: Background worker completely cleans binaries, shortcuts, and registry entries, then terminates and purges itself cleanly.
v1.0.0 — Final Master Release
November 1, 2026 · Phase 12 Release Hardening

The definitive release of QuickDock for Windows 11. Incorporates full multi-monitor support, refined monochrome aesthetic, standalone setup installer, and sub-millisecond hover interaction.

Multi-Monitor & Interaction

  • NotchWindowManager: Spawns an independent notch window across all active displays simultaneously.
  • Dynamic Topology Detection: Automatically repositions notch windows when displays are connected, disconnected, or resolution changes.
  • Deterministic State Machine: 150ms hover trigger debounce and 200ms grace period on mouse leave eliminate accidental closures.

Visual Design & UI/UX Alignment

  • Monochrome Palette: True black (#0A0A0C) background, charcoal cards (#141417), pure white (#FFFFFF) radial progress rings on dark track (#27272A).
  • Dedicated Settings: Comprehensive settings window featuring General, Notch preview, Appearance, Modules, Live Activities, and Privacy tabs.
  • 2x2 System Cards: Battery, Network, Performance, and Audio Volume with live sparklines.
  • Screen Time: Today limit gauge, 7-day retrospective sparkline bars, and per-app usage percentage breakdown.

Packaging & Distribution

  • Self-Contained Installer: Standalone single-file executable QuickDock-1.0.0-win-x64.exe.
  • Zero Dependencies: Bundles .NET 10.0 runtime and Windows App SDK binaries.
  • Zero Telemetry: 100% offline, local-first SQLite database.
