Privacy Policy

Effective Date: November 1, 2026. Zero telemetry, zero analytics, local-first by design.

Short Version

QuickDock does not track you, does not phone home, does not sell data, does not use analytics SDKs, and has no backend servers. Everything stays on your computer.

1. Information We Collect

QuickDock collects no personal data. There are no user accounts, no login screens, no cloud sync, and no tracking identifiers.

2. Local Data Storage

All application data (including your clipboard history, quick notes, pinned items, and screen time metrics) is stored exclusively in a local SQLite database residing inside your user folder: 

%LocalAppData%\QuickDock\quickdock.db

This file is never uploaded or transmitted to any third-party server.

3. Network Communications

QuickDock makes network requests only in the following explicit scenarios:

  • Weather Forecast: If enabled, calls public weather APIs strictly to fetch weather conditions for your designated location. No personal or device identifier is transmitted.
  • LAN QuickDrop: Local network file transfers occur peer-to-peer over your private Wi-Fi network using standard TCP sockets. No files ever touch the public internet.

4. Open Source Verification

QuickDock is fully open source under the MIT License. Anyone can audit the complete codebase, network handlers, and database queries at https://github.com/jojin1709/QuickDock.
