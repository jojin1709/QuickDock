Instant Clipboard History

Search, pin, and paste anything you copied. Protected by automatic secret detection and encrypted local storage.

Privacy & Security First

Zero Leaks. Built-in Data Sanitization.

QuickDock inspects copied text on the fly using pattern recognition to detect sensitive tokens, API keys, private passwords, and credit card numbers.

  • Auto-masking keeps passwords shielded on screen.
  • Configurable ignore rules for password managers (1Password, Bitwarden, KeePass).
  • Stored in a local, encrypted SQLite database with optional auto-purge after 24h, 7 days, or 30 days.
