Installation

QuickDock is distributed as a single standalone executable installer: QuickDock-1.0.0-win-x64.exe.

  1. Download the installer from the Download page or GitHub Releases.
  2. Run QuickDock-1.0.0-win-x64.exe. The installer will unpack files to %LocalAppData%\QuickDock and register startup shortcuts.
  3. QuickDock starts immediately and pins itself to the top of your screen.
Portable & Silent Installation

You can execute the setup silently using the /S flag from any command prompt or automated deployment script.

First Launch & Interaction

When QuickDock starts, it displays a minimal notch capsule centered at the top of your display showing the current time and battery percentage.

  • Hovering: Move your mouse cursor into the notch area. After a 150ms debounce period, the dock smoothly expands into the full dashboard.
  • Auto-Collapsing: Moving your mouse out of the expanded dock activates a 200ms grace period. If your cursor remains outside the dock boundary, it smoothly collapses back into the resting notch capsule.
  • Pinning: You can click the settings icon or toggle the visibility mode in Settings to keep the dock pinned open.

Global Keyboard Shortcuts

QuickDock registers global Windows hotkeys so you can access your tools from any active application or full-screen game:

Shortcut Action
Ctrl + Space Toggle Notch Expand / Collapse (on cursor's active monitor)
Win + Shift + V Directly jump to Clipboard History view
Esc Collapse notch immediately

Multi-Monitor Setup

QuickDock automatically recognizes all connected physical monitors upon startup. If you add or remove an external display while QuickDock is running, the app catches the WM_DISPLAYCHANGE event and automatically generates a new notch window on the added display without needing a restart.

Configuring Modules

You can selectively enable or disable dock modules in Settings → Modules. Modules that are toggled off are not instantiated into memory, preserving RAM. Available modules include:

  • Essentials: Home Dashboard, System Monitor, Timers & Stopwatches, Weather Forecast, World Clock, Calendar.
  • Productivity: Clipboard History, Quick Notes, File Shelf, LAN Drop, Unit Converter, Quick Links, Flash Messages.
  • Insights: Screen Time Tracker, Process Resource Inspector.

Database & Reset

All configuration and local history is stored under: 

%LocalAppData%\QuickDock\quickdock.db

To perform a complete factory reset, quit QuickDock and delete the %LocalAppData%\QuickDock folder.
