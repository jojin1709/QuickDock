PRECISION MECHANICS

The State Machine Cycle

QuickDock operates using a deterministic finite state machine (FSM) that eliminates UI flickers, false triggers, and accidental closures.

  • Resting: 160×28px minimal capsule displaying clock and battery percentage.
  • Hover Trigger: 150ms debounce window prevents unintended expansions when passing cursor across the bezel.
  • Expanded: 640×440px dashboard displaying metrics, clipboard, timers, and modules.
  • Auto-Collapse: 200ms grace period keeps dock open when briefly traversing edges or switching focus.
Deterministic FSM Lifecycle
[RESTING] ── Pointer Approaches ──>
[EXPANDING] ── 150ms Debounce Verified ──>
[EXPANDED] ── Active Dashboard Interaction
[COLLAPSING] ── 200ms Grace Period ──>
[RESTING] ── Idle State (45 MB RAM, <0.2% CPU)
MULTI-MONITOR ARCHITECTURE

Seamless Dual & Triple Display Support

QuickDock's NotchWindowManager queries Win32 display topology upon launch and monitors dynamic display changes via WM_DISPLAYCHANGE.

  • Independent notch instances instantiated on every physical display.
  • Per-monitor DPI awareness ensures pixel-crisp rendering on 100%, 125%, 150%, and 200% scaling factors.
  • Hotkeys automatically route to whichever display your cursor currently occupies.
