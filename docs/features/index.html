Modular Architecture. Infinite Utility.

Every utility is built as an independent, lightweight module loaded on-demand to keep idle resource footprint near zero.

Module 01

Hardware Telemetry & Battery Health

Keep tabs on your PC without heavy overlays. QuickDock provides low-overhead CPU, RAM, and storage utilization gauges, battery discharge rates, thermal warnings, and a process inspector that pinpoints rogue background tasks.

  • Radial rings and sparkline graphs
  • Detailed 2x2 cards for Battery, Network, Performance, and Audio Volume
  • Zero-latency WMI and Win32 performance counter interop

Module 02

Screen Time & Productivity Insights

Gain clarity on your work habits without sending data to external servers. QuickDock measures foreground window focus time, tracks application usage, and displays daily goals with a 7-day retrospective chart.

  • Per-app breakdown with percentage bar visualization
  • Configurable daily screen time limits with gentle notifications
  • Encrypted local SQLite storage with zero network access

Module 03

Developer Swiss Army Knife

Never Google for online converters or open untrusted formatting websites again. Everything you need to inspect, format, and debug payloads lives right inside the notch.

  • JSON formatter, validator, and minifier with syntax error reporting
  • Base64 text and image encoder/decoder
  • UUID/GUID v4 generator with uppercase/hyphen options
  • UNIX timestamp converter with millisecond resolution
  • Developer process port inspector (`netstat` correlation)
