# QuickDock UI Review Guidelines

## Color Palette & Theme
- Background surfaces: `#09090B` (Canvas), `#121214` (Cards/Panels), `#18181B` (Hover states).
- Border strokes: `#27272A` (Subtle 1px border).
- Text: Primary `#FFFFFF` (100% white), Secondary `#A1A1AA` (Zinc 400), Muted `#71717A` (Zinc 500).
- Accents: Restrained electric blue / cyan (`#3B82F6` / `#06B6D4`) used strictly for active indicators and focus rings.
- No cyberpunk, no neon glow, no excessive gradients.

## Interaction & Accessibility
- Visible keyboard focus indicators on all interactive buttons and list items.
- Hit targets: Minimum 32x32px for icon buttons, minimum 40px height for interactive tiles.
- Escape key collapses expanded panels cleanly back to idle notch.
